Forward Substitution

Lower triangular

For a lower triangular system Ax=b, each unknown is obtained from top to bottom.

1. StartSet x = 0 and begin with i = 1.
2. Sum known termsCompute Σ A(i,j)x(j) for j = 1,...,i−1.
3. Solve x(i)Use x(i) = [b(i) − sum]/A(i,i).
n = length(b);
x = zeros(n,1);

for i = 1:n
    sum = 0;
    for j = 1:i-1
        aij = A(i,j);
        x_j = x(j);
        sum = sum + aij*x_j;
    end
    x(i) = (b(i) - sum)/A(i,i);
end

disp(x)
Key idea: when calculating x(i), all previous x(1),...,x(i−1) are already known.

Backward Substitution

Upper triangular

For an upper triangular system, computation starts at the last equation and proceeds upward.

n = 3;
x = zeros(n,1);

for i = n:-1:1
    sum = 0;
    for j = i+1:n
        aij = A(i,j);
        x_j = x(j);
        sum = sum + aij*x_j;
    end
    x(i) = (B(i) - sum)/A(i,i);
end
Direction: n → n−1 → ... → 1.

Forward Permuted System

Pivot ordering

The row permutation vector p changes which row is used at each forward-substitution step.

A = [7 3 0;
     2 5 6;
     4 0 0];

b = [10; 22; 4];
p = [3; 1; 2];

n = length(b);
x = zeros(n,1);

for i = 1:n
    sum = 0;
    for j = 1:i-1
        apj = A(p(i),j);
        x_j = x(j);
        sum = sum + apj*x_j;
    end
    x(i) = (b(p(i)) - sum)/A(p(i),i);
end
Permutation: p = [3; 1; 2] means row 3 is used first, then row 1, then row 2.

Backward Permuted System

Pivot ordering

This combines a row permutation with backward substitution. The loop runs from n down to 1.

n = length(b);
x = zeros(n,1);

for i = n:-1:1
    sum = 0;
    for j = i+1:n
        apj = A(p(i),j);
        x_j = x(j);
        sum = sum + apj*x_j;
    end
    x(i) = (b(p(i)) - sum)/A(p(i),i);
end
Direction: n → 1 while using the permuted row p(i) at every step.
